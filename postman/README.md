# Postman setup

1. Open Postman and choose **Import**.
2. Import `Platzi-Fake-Store.postman_collection.json`.
3. Open the collection variables and set `email` and `password` for a test account when using Login. Do not commit real passwords or tokens.
4. Run **Get all products** first. Run **Login (save tokens)** before **Get current profile**.

Base URL: `https://api.escuelajs.co/api/v1`

The API is a public demo backend. Its data may reset or change, and it is not suitable for production customer accounts or sensitive data.
